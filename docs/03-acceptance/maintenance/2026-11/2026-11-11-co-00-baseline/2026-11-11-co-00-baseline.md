## 3. 安全发现与修复

### 3.1 follow-redirects（Trivy HIGH）

- 失败基线：`main @ 1fb5e74` 的 Security run `42646521102` 失败，Trivy 指向 `frontend/package-lock.json` 中 `follow-redirects` 1.16.1，CVE-2026-116689（HIGH），修复版本 1.16.2。
- 依赖路径：`axios@1.20.0` 声明 `follow-redirects: ^1.16.0`，锁文件此前解析到 1.16.1。
- 修复方式：`frontend/package.json` 的 `overrides` 显式锁定 `follow-redirects: 1.16.2`，并更新 `package-lock.json`；未使用 `--force`，未文本替换版本号。
- CVE 与版本对应：1.16.1 关闭 CVE-2026-111755 / CVE-2026-111756；1.16.2 进一步关闭 CVE-2026-116689。

### 3.2 guava / snappy-java

- 引入路径：`io.minio:minio:9.0.1`（`backend/pom.xml`）的 Maven 传递依赖。
- 钉版位置：`backend/pom.xml` 的 `dependencyManagement`——`guava 33.7.2-jre`、`snappy-java 1.1.10.9`。
- 实际产物核对：Docker 构建日志显示最终镜像内为 `guava-33.7.2-jre.jar` 与 `snappy-java-1.1.10.9.jar`（不是仅改 pom 未生效）。
