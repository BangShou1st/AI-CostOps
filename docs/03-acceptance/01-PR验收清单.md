# 01. PR 验收清单

这份清单首先由 PR Author 自检；如果邀请 Peer Review，Reviewer 只需检查与本 PR 相关的条目，不需要重读全部设计文档。

## 通用

```text
[ ] 对应 GitHub Issue / AIC
[ ] Scope 没有偷偷扩大
[ ] CI Green
[ ] 必要的讨论 / Review 已处理
[ ] 没有 Secret / Raw Provider File / Generated Build Output
```

## Backend

```text
[ ] Module Boundary 正确
[ ] Transaction Boundary 正确
[ ] BigDecimal / DECIMAL
[ ] Flyway 已提交
[ ] Constraint / Index 有理由
[ ] Failure Path Test
```

## API

```text
[ ] openapi.yaml 已同步
[ ] Request / Response Schema 一致
[ ] Permission / Scope 一致
[ ] Error Code 一致
[ ] Frontend Type / Client 已同步或有明确依赖 Issue
```

## Redis

```text
[ ] Key / TTL / Failure Policy 明确
[ ] 没把 Redis 变成 Ledger/Budget Truth
```

## Financial Core

```text
[ ] Idempotency
[ ] Concurrency
[ ] Rollback
[ ] CLOSED/CLOSING Guard
[ ] Ledger Immutable
```

## Provider Import

```text
[ ] Raw Evidence 保留
[ ] Unknown Field 没被静默吞掉
[ ] 没猜 Provider 语义
[ ] Sanitized Fixture
[ ] Parser Version / Schema Drift Test
```

## Frontend

```text
[ ] 不自己发明 API 字段
[ ] 不使用 Error Detail 字符串判断业务
[ ] Money / ID Type 正确
[ ] Backend 仍是 Authorization Truth
```
