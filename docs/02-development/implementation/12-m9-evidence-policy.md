# M9 Evidence Policy

Every M9 completion claim must be backed by fresh evidence from the implementation branch/PR or merged candidate.

Accepted evidence:

```text
test output
CI checks
benchmark report
EXPLAIN ANALYZE
restore drill
alert injection/recovery
browser E2E report
security scan
redacted Provider certification
human acceptance record
```

Not accepted:

```text
agent says PASS
previous V1 evidence reused as M9 execution
synthetic Provider fixture presented as real certification
unrecorded local manual test
performance extrapolation
```
