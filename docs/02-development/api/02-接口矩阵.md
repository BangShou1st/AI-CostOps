# 02. M1 接口矩阵

> 本矩阵与 `openapi.yaml` 同步。所有业务管理接口都从认证上下文取得当前组织，不接受客户端提供的组织边界。未列出的 M2 与 Organization CRUD 接口不属于 M1。

所有 ID、`securityVersion` 与 `expectedVersion` 均为十进制 JSON string。标为“分页”的接口使用 `page`（默认 0）、`size`（默认 50，最大 200）及 `PageResponse<T>{items,page,size,totalElements,totalPages}`。

## Authentication

| Method | Path | Security | Success |
|---|---|---|---:|
| POST | `/auth/register` | Public + feature flag | 200 |
| POST | `/auth/login` | Public | 200 |
| POST | `/auth/refresh` | Refresh cookie + Origin | 200 |
| POST | `/auth/logout` | Bearer + refresh cookie + Origin | 204 |
| POST | `/auth/logout-all` | Bearer | 204 |
| POST | `/auth/password/forgot` | Public | 202 |
| POST | `/auth/password/reset` | Reset token | 204 |
| GET | `/auth/me` | Bearer | 200 |
| POST | `/invitations/{token}/accept` | Invitation token | 200 |

`GET /auth/me` 保持既有身份字段，仅新增排序、去重的 M1 admin `permissions:string[]`；不暴露 scope ID 或 role code。过期 security version 返回 `401 AUTH_SESSION_EXPIRED`。

## IAM administration

| Method | Path | Permission / scope | Shape | Success |
|---|---|---|---|---:|
| GET | `/users` | `USER_READ` / ORG | 分页完整 User | 200 |
| GET | `/users/{id}` | `USER_READ` / ORG | 完整 User | 200 |
| PATCH | `/users/{id}/status` | `USER_MANAGE` / ORG，fresh | `{status,expectedVersion:string}` → User | 200 |
| GET | `/roles` | `ROLE_READ` / ORG | unpaged Role catalog | 200 |
| GET | `/permissions` | `ROLE_READ` / ORG | unpaged Permission catalog | 200 |
| POST | `/role-assignments` | `ROLE_ASSIGN` / ORG，fresh | explicit role + scope | 201 |
| DELETE | `/role-assignments/{id}` | `ROLE_ASSIGN` / ORG，fresh | semantic grant revoke | 204 |
| POST | `/invitations` | `USER_INVITE` / ORG | metadata only; no raw token | 201 |

User 在 list/detail/status response 中使用同一个完整模型：`id,email,displayName,status,securityVersion,organizationMember,roleAssignments[]`。`securityVersion` 是 durable MySQL version 的十进制 string。status mutation 必须提交显示值原样作为 `expectedVersion:string`；stale version 是 `409 STATE_CONFLICT`，客户端不得自动覆盖。

Role assignment 只接受四种 frozen scope：`ORG|PROJECT|TEAM|COST_CENTER`。非法 Role/scope pair 是 400；不可见/跨组织 scope 是 privacy-preserving 404；自然键重复是 409。

Invitation 默认 72 小时、允许 1–168 小时。delivery 不可用或失败是 503；raw token 不进入 response、audit 或 log。

## Organization master data and membership

| Method | Path | Permission / scope | Shape | Success |
|---|---|---|---|---:|
| GET | `/projects` | `PROJECT_READ` / ORG or PROJECT | 分页 | 200 |
| POST | `/projects` | `PROJECT_MANAGE` / ORG | `{code,name}` | 201 |
| PATCH | `/projects/{id}` | `PROJECT_MANAGE` / ORG or PROJECT | `{name?,status?}` | 200 |
| GET | `/projects/{id}/members` | `PROJECT_READ` or `PROJECT_MEMBER_MANAGE` | 分页 | 200 |
| POST | `/projects/{id}/members` | `PROJECT_MEMBER_MANAGE` | `{organizationMemberId}` | 201 |
| DELETE | `/projects/{id}/members/{memberId}` | `PROJECT_MEMBER_MANAGE` | lifecycle disable | 204 |
| GET | `/teams` | `TEAM_READ` / ORG or TEAM | 分页 | 200 |
| POST | `/teams` | `TEAM_MANAGE` / ORG | `{code,name}` | 201 |
| PATCH | `/teams/{id}` | `TEAM_MANAGE` / ORG or TEAM | `{name?,status?}` | 200 |
| GET | `/teams/{id}/members` | `TEAM_READ` or `TEAM_MANAGE` | 分页 | 200 |
| POST | `/teams/{id}/members` | `TEAM_MANAGE` | `{organizationMemberId}` | 201 |
| DELETE | `/teams/{id}/members/{memberId}` | `TEAM_MANAGE` | lifecycle disable | 204 |
| GET | `/cost-centers` | `COST_CENTER_READ` / ORG or COST_CENTER | 分页 | 200 |
| POST | `/cost-centers` | `COST_CENTER_MANAGE` / ORG | `{code,name}` | 201 |
| PATCH | `/cost-centers/{id}` | `COST_CENTER_MANAGE` / ORG or COST_CENTER | `{name?,status?}` | 200 |
| GET | `/provider-accounts` | `PROVIDER_ACCOUNT_READ` / ORG | 分页 | 200 |
| POST | `/provider-accounts` | `PROVIDER_ACCOUNT_MANAGE` / ORG | provider fields | 201 |
| PATCH | `/provider-accounts/{id}` | `PROVIDER_ACCOUNT_MANAGE` / ORG | editable provider fields | 200 |

Project/team/cost-center `code` 与 provider `providerCode` 在创建后不可变。生命周期为 `ACTIVE|DISABLED|ARCHIVED`，不提供 master-data hard delete。membership DELETE 也是状态转换；membership 路径中的 `{memberId}` 是 membership row ID。

Provider account 没有 generic `code`。`providerCode` immutable；`displayName`、`externalAccountRef`、`status`、非秘密 `metadata` 可编辑。metadata 禁止 credentials/API keys。

## Scope and error boundary

- 所有 list 的 rows/count 使用相同 organization、scope、status/filter predicate；禁止 SELECT-all 后 Java filtering。
- TEAM 不隐式继承 PROJECT，PROJECT 不隐式继承 COST_CENTER。
- 缺少 permission 是 403；不存在、跨 org、out-of-scope 统一为 404，detail 不得区分原因。
- create 需要 ORG scope；resource-scoped grant 只允许读取/修改匹配 ID。
- unsupported method/path 不开放；最终 security matcher 保持 `denyAll`。
