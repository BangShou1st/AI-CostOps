# 02. V1 接口矩阵

> Endpoint 必须与 `openapi.yaml` 保持一致。

## Auth / IAM

| Method | Path | 主要权限 | 幂等/并发 |
|---|---|---|---|
| POST | `/auth/register` | Public + Feature Flag | Email Unique |
| POST | `/auth/login` | Public | Rate Limit |
| POST | `/auth/refresh` | Refresh Cookie | Rotation |
| POST | `/auth/logout` | Authenticated | Repeat-safe |
| POST | `/auth/logout-all` | Authenticated | Repeat-safe |
| POST | `/auth/password/forgot` | Public | Rate Limit |
| POST | `/auth/password/reset` | Reset Token | Single-use |
| GET | `/auth/me` | Authenticated | Read |
| POST | `/invitations/{token}/accept` | Invitation Token | Single-use |
| GET | `/users` | `USER_READ` | Read |
| GET | `/users/{id}` | `USER_READ` | Read |
| PATCH | `/users/{id}/status` | `USER_MANAGE` | `expectedVersion` |
| GET | `/roles` | `ROLE_READ` | Read |
| GET | `/permissions` | `ROLE_READ` | Read |
| POST | `/role-assignments` | `ROLE_ASSIGN` | Natural uniqueness |
| DELETE | `/role-assignments/{id}` | `ROLE_ASSIGN` | State-aware |
| POST | `/invitations` | `USER_INVITE` | Idempotency-Key 推荐 |
